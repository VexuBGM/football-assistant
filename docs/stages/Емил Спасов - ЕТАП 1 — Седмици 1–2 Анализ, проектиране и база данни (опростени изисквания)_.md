# **📌 Информационна система за управление на футболни клубове**

---

# **1\) Анализ на проекта**

## **🔹 Описание на проекта**

Проектът представлява уеб базирана система за управление на футболни клубове.  
Тя позволява съхраняване и управление на информация за клубове, играчи и мачове.

Системата решава проблема с разпокъсаното съхранение на информация (Excel, тетрадки, отделни файлове) и предоставя централизирана база данни.

---

## **🔹 Основни функции (минимум 5\)**

1. Добавяне на нов клуб  
2. Редактиране на информация за клуб  
3. Изтриване на клуб  
4. Добавяне на играч към клуб  
5. Преглед на списък с всички клубове  
6. Преглед на всички играчи в даден клуб  
7. Записване на мач между два клуба  
8. Филтриране на мачове по дата

---

## **🔹 Основни обекти (таблици)**

* **Clubs**  
* **Players**  
* **Matches**

---

# **2\) ER диаграма (опростено)**

## **Таблици и полета**

### **Clubs**

* club\_id (PK)  
* name  
* city  
* founded\_year

### **Players**

* player\_id (PK)  
* name  
* age  
* position  
* club\_id (FK)

### **Matches**

* match\_id (PK)  
* home\_club\_id (FK)  
* away\_club\_id (FK)  
* match\_date  
* home\_score  
* away\_score

---

## **Връзки**

* Един клуб има много играчи (1:N)  
* Един клуб може да участва в много мачове (1:N)  
* Всеки играч принадлежи на един клуб

(Може да се нарисува в draw.io с 3 таблици и стрелки между тях.)

# **3\) Избор на база данни**

Избрана база данни: **SQLite**

Причина:  
SQLite е лека, лесна за настройка и не изисква отделен сървър. Подходяща е за учебни и малки проекти.

---

# **4\) schema.sql**

```sql
CREATE TABLE Clubs (
    club_id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    city TEXT NOT NULL,
    founded_year INTEGER
);

CREATE TABLE Players (
    player_id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    age INTEGER NOT NULL,
    position TEXT NOT NULL,
    club_id INTEGER NOT NULL,
    FOREIGN KEY (club_id) REFERENCES Clubs(club_id)
);

CREATE TABLE Matches (
    match_id INTEGER PRIMARY KEY AUTOINCREMENT,
    home_club_id INTEGER NOT NULL,
    away_club_id INTEGER NOT NULL,
    match_date DATE NOT NULL,
    home_score INTEGER,
    away_score INTEGER,
    FOREIGN KEY (home_club_id) REFERENCES Clubs(club_id),
    FOREIGN KEY (away_club_id) REFERENCES Clubs(club_id)
);
```
