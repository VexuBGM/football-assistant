## **ЕТАП 3 — CRUD „Футболисти“ \+ филтри**

### **Цел**

Пълен модул `players` с връзка към `clubs`.

### **Задължителни изисквания**

* Таблица `players`:  
  * FK към `clubs`  
  * полета: `full_name`, `birth_date`, `nationality`, `position`, `number`, `status`  
* CRUD операции:  
  * добавяне на играч (вкл. избор/намиране на клуб)  
  * списък играчи \+ филтър „по клуб“  
  * редакция (позиция/номер/статус)  
  * изтриване  
* Валидация:  
  * `position ∈ {GK, DF, MF, FW}`  
  * номер: 1–99 (или 1–30 по избор)  
  * дата на раждане валиден формат  
* Чатбот команди минимум:  
  * „Добави играч … в … позиция … номер …“  
  * „Покажи играчи на \<клуб\>“  
  * „Смени номер на … на …“  
  * „Изтрий играч …“

### **Артефакти**

* `players_service.py` \+ тестови данни  
* примерен диалог с 8–10 реплики (клубове \+ играчи)
